## Page 24
**Density model WITHOUT noise — dimensional profile only.** Decima Engine, 2022.
- Same split as page 21 (Vertical Profile left / Envelope right) but rendered with the noise term absent or neutral, showing only the underlying "dimensional profile" shapes: both sides are completely smooth, soft, blobby forms — the vertical-profile side shows smooth flattened lens/pancake masses in a blue sky (edges smooth and rounded, shading pale blue-grey in crevices, white on top); the envelope side shows one giant perfectly smooth cream-colored mound in pink dusk haze (looks like smooth dough — no surface detail at all).
- Code, exact:
```c
// Define Cloud Density
cloud_density = saturate(noise - (1.0 - dimensional_profile));
```
- This is the core Nubis density equation: the **dimensional profile** (0..1 macro shape field) remaps the noise; where the profile is 1 the noise passes through fully, where it approaches 0 the noise is subtracted away (erosion), producing detailed edges only near the shell of the macro shape.

## Page 29
**Direct scattering model.** Footnote citations: (1) Augustus Beer, "Bestimmung der Absorption des rothen Lichts in farbigen Flüssigkeiten", Annalen der Physik und Chemie, vol. 86, pp. 78-88, 1852; (2) L. ## Page 32
**"Nubis Ambient Scattering Approximation".** Citation footer (Schneider 2022).
- Diagram: a light-grey cauliflower cloud with a darker grey outline/rim; light-blue arrows point inward onto the cloud from above and from the upper sides (sky-dome light arriving from all directions above the cloud surface).
- Code, exact:
```c
float ambient_scattering = pow(1.0 - dimensional_profile, 0.5);
```
- Key fact: ambient scattering amount is derived **from the dimensional profile itself** — sqrt of (1 - profile). At the cloud shell (profile→0) ambient is maximal (1.0); deep inside (profile→1) ambient goes to 0. I.e. ambient is a cheap depth-into-cloud occlusion proxy: the sky contribution penetrates the outer shell and is progressively extinguished toward the core, with a sqrt (soft/perceptual) falloff. No sky color is shown on this slide — only the scalar amount; the (blue) sky light color multiplies it per the page-28 decomposition.

## Page 40
**Distance-based step size.** Citation footer (Schneider 2022).
- Diagram: camera icon with red sample dots along a horizontal ray; dot spacing increases with distance from the camera.
- Code, exact:
```c
// Define step size constants
float near_step_size = 3.0;
float far_step_size_offset = 60.0;
float step_adjustment_distance = 16384.0;

// Calculate distanced-based step size
float step_size = near_step_size + ((far_step_size_offset * distance_from_camera) / step_adjustment_distance);
```
- I.e. step size grows linearly from 3.0 near the camera by +60.0 per 16384.0 units of distance.
