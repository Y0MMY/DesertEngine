## Page 104
- **Slide title**: "Dimensional Profile" (black slide, diagram + code).
- **Diagram**: A horizontal black→white gradient bar labeled "Dimensional Profile". Left end labeled **"Low Frequency Billows"**, right end **"High Frequency Billows"** — i.e. the dimensional profile value itself selects the billow frequency: deep inside the cloud (low profile) uses low-frequency billows, near the surface (high profile) uses high-frequency billows.
- **Code (verbatim)**:
  ```
  // Define billowy noise
  float billowy_type_gradient = pow(inDimensionalProfile, 0.25);
  float billowy_noise = lerp(noise.b * 0.3, noise.a * 0.3, billowy_type_gradient);

  // Define Noise composite - blend to wispy as the density scale decreases.
  float noise_composite = lerp(wispy_noise, billowy_noise, inType);
  ```
  Notes: `noise.b` = low-frequency billow channel, `noise.a` = high-frequency billow channel, both attenuated by `* 0.3`; the blend factor is `pow(inDimensionalProfile, 0.25)` (biases strongly toward high-frequency billows except at the very core). `inType` blends the composite from wispy noise to billowy noise.

## Page 113
- **Slide**: Black slide, a 1-D waveform plot (jagged signal oscillating around a horizontal axis line — illustrating the shaped noise signal) + code.
- **Code (verbatim)**:
  ```
  float hhf_wisps = 1.0 - pow(abs(abs(noise.g * 2.0 - 1.0) * 2.0 - 1.0), 4.0);
  float hhf_billows = pow(abs(abs(noise.a * 2.0 - 1.0) * 2.0 - 1.0), 2.0);
  ```
  Notes: both are "high high frequency" detail signals built by double abs-folding a noise channel from [0,1] into a ridged signal. Wisps: inverted, exponent **4.0**, from `noise.g`. Billows: not inverted, exponent **2.0**, from `noise.a`.
- **Speaker notes**: none in extraction.

## Page 118
- **Slide**: Top half = the isolated cumulus render (final result, same cloud as pages 109–111, fully detailed). Bottom half = the closing code of the density sampler.
- **Code (verbatim)**:
  ```
  // Composite Noises and use as a Value Erosion
  float uprezzed_density = ValueErosion(inDimensionalProfile, noise_composite);

  // Apply User Density Scale Data to Result
  uprezzed_density *= inDensityScale;

  // Sharpen result and lower Density close to camera to both add details and reduce undersampling noise
  uprezzed_density = pow(uprezzed_density, lerp(0.3, 0.6, max(EPSILON, pow(saturate(inDensityScale), 4.0))));

  // Return result
  return uprezzed_density;
  ```
  Notes: the noise composite erodes the dimensional profile via a `ValueErosion` function (value-erosion, not simple subtraction); result is multiplied by the authored per-voxel `inDensityScale`; then a density-scale-dependent sharpening `pow` with exponent lerped between **0.3** and **0.6** driven by `pow(saturate(inDensityScale), 4.0)` (clamped by `EPSILON`) — low density scale ⇒ exponent near 0.3 (lifts/softens thin media), high density scale ⇒ 0.6.
- **Speaker notes**: none in extraction.
