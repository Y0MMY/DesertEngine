## Page 163
**Header:** Nubis³ / Voxel Clouds / Ray-Marching.
**Content:** Diagram + pseudo-code for the hybrid sample-placement scheme.
**Diagram:** Camera at left, ray to the right passing under/through two big gray cumulus blobs. Two labeled bracket regions over the ray: "SDF Sample Placement" (first region, before the ray enters cloud — hollow red circles as samples, green dashed arrows pointing from those samples down to the nearest cloud surface, i.e. the SDF distance) and "Adaptive Sample Placement" (second region, inside/along the cloud — filled red dots as samples with progressively wider dashed step arrows).
**Pseudo-code (verbatim):**
```
sdf_cloud_distance = GetVoxelCloudDistance(sample_pos);

adaptive_step_size = max( 1.0, max(sqrt(distance_from_camera), EPSILON) * 0.08);

jitter_offset = distance_from_camera < 250.0 ? animated_hash : static_hash   // (boxed/highlighted line)

step_size = max(sdf_cloud_distance, adaptive_step_size) + jitter_offset;

sample_pos = distance_from_camera + view_direction * step_size;
```
**Constants:** minimum step 1.0; adaptive scale factor 0.08 on sqrt(distance_from_camera); jitter switches from animated hash to static hash at distance 250.0 (units are metres per the later "200 m" rendering slide). The `jitter_offset` line is drawn with a white highlight box (emphasized on this slide).

## Page 164
**Header:** Nubis³ / Voxel Clouds / Ray-Marching.
**Content:** What happens when a sample lands inside the cloud. Diagram: a gray cumulus; a hollow red circle outside it (sample not in cloud) and a filled red dot inside it (sample in cloud). From the in-cloud sample a vertical callout stack lists, top to bottom:
- "Sample Secondary Light Energy"
- "Sample Ambient Light Energy"
- "Sample Direct Light Energy"
- "Sample Density"

**Pseudo-code (verbatim):**
```
if (sdf_cloud_distance < 0.0)
{
    voxel_cloud_sample_data = GetVoxelCloudSampleData();

    IntegrateCloudSampleData(voxel_cloud_sample_data, pixel_data);
}
```
Interpretation: a negative SDF value means "inside cloud"; only then is the voxel sample fetched. The voxel cloud sample data bundles FOUR channels per sample: density, direct light energy, ambient light energy, and secondary light energy — i.e. ambient is a precomputed/stored per-voxel lighting quantity sampled during the march, not computed per-pixel at march time.

**Header:** Nubis³ / Voxel Clouds / Production. Caption bottom-left: "Samsung Galaxy S21Ultra" (i.e. a real photograph, not a render).
**Content:** Real reference photo of a massive shadowed cumulus: the giant central cloud body is in its own shadow and reads as flat blue-gray (sky-tinted ambient only), while surrounding sunlit cumulus tops at the right and below are bright white with strong contrast; sky patches at left are saturated blue; a darker gray cloud shelf hangs across the very top.
