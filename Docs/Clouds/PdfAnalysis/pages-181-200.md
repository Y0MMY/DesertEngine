## Page 187
- **Header:** `Nubis³ / Conclusions`.
- **Content:** Feature comparison table of the three Nubis cloud methods (verbatim, Yes in green / No & caveats in red):

  | | Vertical Profile Method | Envelope Method | Voxel Method |
  |---|---|---|---|
  | Evolution | Yes | Pseudomotion Only | Pseudomotion Only |
  | Time Of Day | Yes | Yes | Yes |
  | Lightning | Yes | No | Yes |
  | Terrain-Cast Shadows | No | Yes | Yes |
  | High Frame-rates | Yes | Yes | Yes |
  | Flight-Capable | No | Yes | Yes |
  | Freeform Modeling | No | No | Yes |

- **Takeaway:** the voxel method wins on everything except true evolution (it only supports "pseudomotion" — animated noise/scroll rather than real simulated cloud evolution, which only the vertical-profile method offers). Only the voxel method allows freeform modeling.
- No formulas.

- **No math in this range.** Pages 181-200 contain zero formulas, pseudo-code, or shader constants; the only numbers are sequencer UI values on p.183 (Start Frame 0, Stop Frame 360, translation vectors like [3134 -2847 544]) and the p.187 feature table.
