# Тестовые сцены облаков

Девять сцен для первой визуальной проверки объёмных облаков. Значения облачных полей взяты
**из настоящей таблицы пресетов** (`Engine/Graphic/CloudPresets.hpp`) генератором, а не набраны руками:
если таблицу в коде поправят, сцены надо перегенерировать, иначе они разойдутся с движком.

Каждая сцена: солнце (directional light, по умолчанию оно же атмосферное), сущность `Sky` с компонентами
`Sky Atmosphere` и `Volumetric Clouds`, и земля из `Starter` для масштаба.

| Сцена | Что смотреть |
|---|---|
| `Clouds_Clear` | Почти пустое небо, покрытие 0.06. Если небо затянуто — покрытие не доезжает до weather map. |
| `Clouds_FairWeather` | Редкие кучевые. Базовый «нормальный» вид. |
| `Clouds_PartlyCloudy` | Значения по умолчанию компонента. Сравнивать с тем, что даёт свежедобавленный компонент. |
| `Clouds_Stratus` | Плоский низкий слой. Проверка высотного градиента: слой обязан быть тонким и низким. |
| `Clouds_Overcast` | Сплошная пелена, небо приглушено. |
| `Clouds_Storm` | Покрытие 0.96, экстинкция 2.0, тёмное небо. Самый тяжёлый по стоимости кадр. |
| `Clouds_Cirrus` | Высокие перистые. |
| `Clouds_Sunset` | Та же погода, солнце у горизонта — проверка закатного окрашивания и фазовой функции на просвет. |
| `Clouds_TimeOfDay` | `Drive Sun From Time Of Day` включён, сутки за 120 секунд. Солнце обязано ехать само. |

## На что смотреть в первую очередь

Разработчики сдали списки того, что здесь непроверяемо. Сведённые в порядке вероятности:

1. **Чтение глубины в compute** — `VUID-VkDescriptorImageInfo-imageLayout` или жалоба на aspect mask.
   Единственное место, где рейммарч опирается на код, который никто не запускал.
2. **`sampler3D` на биндингах 3 и 4 марша.** Если рефлексия классифицирует их как 2D, ошибки не будет —
   будет мусор. Отличать по картинке шума, а не по логу.
3. **`RGBA16F` `Storage|Sample`** — создание цели рассеяния.
4. **Барьер weather → raymarch** внутри кадра.
5. **`LOG_INFO "[CloudNoise] Generated the noise set ... 8.19 MiB"`** — если его нет, шумы не сгенерированы,
   и причина будет в логе рядом, с числами.

## Что заведомо придётся подвинуть

Калибровки физически обоснованы, но глазами не подбирались: экстинкция на мировую единицу
(`5e-4`, т.е. 0.05 на метр) и скорость ветра (60 м/с на единицу силы). Если облака окажутся слишком
плотными или слишком быстрыми — это первые два числа, а не ошибка в марше.
